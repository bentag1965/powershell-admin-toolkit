# Security

## Reporting

If you identify a security issue in one of the example scripts, please avoid publishing secrets, credentials, private infrastructure details, or sensitive third-party data in a public issue.

For this portfolio repository, the preferred pattern is to describe the issue using sanitized reproduction details.

## Scope

These repositories are defensive reference implementations. They intentionally exclude:

- production credentials
- customer information
- employer-specific configuration
- private network details
- proprietary source code

Do not add real secrets to examples, issues, pull requests, or test data.
